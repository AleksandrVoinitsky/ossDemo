# Формирование персонального чек-листа

## Рабочий конвейер

Итоговый чек-лист собирается без обязательного обращения к LLM:

1. Из карточки объекта читаются все известные структурированные признаки.
2. Классификатор присваивает каждому из 49 критериев состояние `included`, `excluded` или `blocked_unknown`.
3. Из утверждённого шаблона выбираются контрольные процедуры тех разделов, в которых есть применимые критерии.
4. Для каждой процедуры сохраняются применимые критерии, нормативное основание, происхождение и подтверждённые идентификаторы требований, если точная связь установлена.
5. Выбранные процедуры переносятся в черновик пакетами до 50 пунктов без изменения их формулировок моделью.

Неизвестные признаки не блокируют запуск. Они остаются в решениях классификатора, а чек-лист формируется только по известной области объекта.

## Ответственность каталогов

- `data/requirements/inspector-checklist-template.jsonl` — источник 235 утверждённых контрольных процедур инспектора.
- `data/requirements/checklist-item-catalog.jsonl` — каталог проверенных связей процедур со строками нормативного реестра. Элементы с происхождением `requirements-registry-direct-v1` не являются контрольными процедурами и в чек-лист не включаются.
- `data/requirements/requirements-registry.jsonl` — нормативная база для трассировки, RAG-ответов и последующего анализа пробелов.
- `data/requirements/classifier-mapping.jsonl` — правила определения применимых направлений контроля по карточке объекта.

Процедура со статусом связи `unmapped` остаётся допустимой, поскольку её формулировка и основание взяты из утверждённого человеческого шаблона. Этот статус не означает точного покрытия отдельной строки реестра и явно сохраняется в трассировке.

## Контрольные объёмы

- объект с подтверждённым отсутствием всех воздействий: 31 базовая процедура раздела 1;
- объект с источниками выбросов: 68 процедур разделов 1 и 2;
- сохранённый профиль Березниковского ЛПУМГ: 179 процедур разделов 1, 2, 3, 4 и 7.

Количество является результатом применимости разделов, а не искусственным лимитом.

## Граница следующего этапа

Следующий самостоятельный этап — извлечение кандидатов фактов карточки из проиндексированных документов. Предложение должно содержать точную цитату и источник и не может перезаписать подтверждённое инспектором значение без отдельного принятия.
