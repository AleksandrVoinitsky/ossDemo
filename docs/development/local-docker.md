# Локальный Docker-стенд

Стенд предназначен для разработки и полного прогона перед отправкой изменений в удалённый репозиторий. Он не подключается к базе хостинга и не использует PostgreSQL, уже работающий на локальном порту `5432`.

## Состав

- приложение: `http://127.0.0.1:18080`;
- PostgreSQL 17 с pgvector: `127.0.0.1:15432`;
- отдельный volume `ossdemo-db-data` для БД;
- отдельный volume `ossdemo-app-data` для моделей и поискового индекса.

## Первый запуск

Локальный `.env.local` создаётся из `.env.local.example` и не отслеживается Git. Для обычного запуска токен LLM не требуется.

```powershell
Copy-Item .env.local.example .env.local
./scripts/local-docker.ps1 Up
```

Первый запуск загружает локальные модели эмбеддингов и reranker размером более 1 ГБ, поэтому может занимать до 15 минут. Проверка ждёт готовность приложения, но немедленно завершается ошибкой, если контейнер остановился.

## Команды

```powershell
./scripts/local-docker.ps1 Status
./scripts/local-docker.ps1 Verify
./scripts/local-docker.ps1 Logs
./scripts/local-docker.ps1 Down
```

`Down` удаляет контейнеры и сеть, но сохраняет данные в volumes. Скрипт намеренно не содержит автоматического удаления volumes.

## Подключение LLM

Для проверки ИИ-консультанта добавьте `AI__ApiToken` только в `.env.local` и пересоздайте приложение:

```powershell
./scripts/local-docker.ps1 Up
```

Не добавляйте `.env.local` в Git и не переносите в него строку подключения к БД хостинга.
