# Экран раздела База знаний

Экран «База знаний» — это центральный интерфейс для управления всеми нормативными документами (законы, СТО, ГОСТ, регламенты), которые используются для поиска требований при генерации чек-листов.

Интерфейс должен обеспечить удобную загрузку, индексацию, привязку к разделам классификатора, просмотр и актуализацию документов.

1. Цель экрана

Загрузка новых документов (одиночная или пакетная) в систему.

Просмотр списка всех загруженных документов с их статусами (индексирован, привязан к разделам, ошибка).

Привязка документа или его фрагментов к разделам классификатора (автоматическая + ручная корректировка).

Поиск по названию, типу, дате, статусу, привязке.

Актуализация — замена документа на новую версию (с сохранением истории).

Удаление / архивация неактуальных документов.

1. Основные функциональные блоки экрана

| Блок                             | Назначение                                         | Элементы                                                                                                                                                                                                                                           |
|----------------------------------|----------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Фильтры и поиск                  | Быстрый поиск и сужение списка                     | Строка поиска (по названию, номеру, дате), фильтр по типу документа (закон, СТО и т.п.), фильтр по статусу индексации (индексирован / ошибка / не привязан), фильтр по разделу классификатора (выпадающий список с деревом)                        |
| Кнопка «Загрузить»               | Инициирует загрузку новых документов               | Основная кнопка, вызывает диалог загрузки (draganddrop или выбор файлов)                                                                                                                                                                           |
| Таблица документов               | Отображение списка с ключевой информацией          | Колонки: Название (ссылка на просмотр деталей), Тип, Номер/дата, Статус (индикатор), Привязанные разделы (количество или список), Дата загрузки, Дата обновления, Действия (просмотр, редактирование привязки, заменить версию, удалить)           |
| Детальная карточка               | Просмотр и редактирование документа                | Открывается по клику на строке или на кнопке просмотра. Содержит: все метаданные, статус индексации, список фрагментов (чанков) с их привязкой к разделам классификатора, возможность редактировать привязку вручную, замену файла, историю версий |
| Панель привязки к классификатору | Управление связями между документом и разделами КК | Древо классификатора с чекбоксами для массовой привязки всего документа к разделам (или детальная привязка отдельных чанков)                                                                                                                       |
| Индикаторы статуса               | Визуальное отображение состояния                   | Цветные метки: ✅ (индексирован и привязан), ⚠️ (индексирован, но есть не привязанные чанки), ❌ (ошибка индексации), 🔄 (в процессе индексации)                                                                                                      |
