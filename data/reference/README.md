# Локальные исходные материалы

Этот каталог предназначен для демонстрационных DOCX/PDF/XLSX, снимков экранов и рабочих материалов. Всё содержимое, кроме этого README, игнорируется Git и не участвует в сборке или публикации.

Рекомендуемые подкаталоги:

- `demo/` — сценарии и функциональные требования в исходных форматах;
- `schedule/`, `checklists/`, `templates/`, `facilities/`, `violations/`, `dictionaries/` — материалы предметных разделов;
- `working/` — временные рабочие материалы;
- `images/` — исходные изображения, не являющиеся web-ресурсами.

Утверждённые Markdown-документы для RAG находятся в `data/knowledge-base/`. Подготовительные текстовые материалы находятся в `data/import/`.
